# Исследовательские процессы и результаты

[Главная](../../README.ru.md) · [English](../en/workflows.md) · [Каталог инструментов](../reference/tools.md)

Выпуск r153/v22 включает [выбор класса модели](model-classes.md); примеры ниже относятся к его опубликованным сценариям.

## Контрактные инструменты и исполняемые сценарии

Зарегистрированные `research_*` проверяют переданные данные: план, бюджет, связь утверждения с фрагментом, запись проверки или структурированный отчёт. Обязательные поля и результат определяются конкретной схемой. Решение по переданным измерениям не доказывает, что измерения были получены независимо.

Сценарии навыка нужны для фактической ограниченной последовательности модельных вызовов, получения источников и сохранения артефактов. Они находятся в `skills/research/scripts/` установленного Research. Сценарии `reconcile_*` работают с предыдущей попыткой и её записями; их наличие не разрешает повторять внешнее действие с неизвестным исходом.

## Точки входа

| Точка входа | Назначение |
|---|---|
| `plan_beta_from_question.py` | Один ограниченный вызов модели без инструментов для плана Search/Deep/Ultra/Academic |
| `run_beta_search.py` | Короткий веб-процесс: выбор источника, кандидат и смысловая проверка, частичный результат или недостаточность доказательств |
| `run_beta_deep_question.py` | Углублённый процесс по вопросу с несколькими семействами источников |
| `run_beta_research.py --mode ultra --domain-first` | Предметная декомпозиция, конкурирующие объяснения, охват, синтез, возражения и контрольные поиски в пределах бюджета |
| `run_beta_research.py --mode academic` | Запечатанный академический протокол, поиск и отбор, дополнительное изучение документов/данных, академическое досье |
| `appraise_beta_papers.py` | Последовательное изучение предоставленных PDF или аннотаций с сохранением положений и пробелов чтения |
| `reanalyze_academic_dataset.py` | Повторный анализ сопоставленных табличных данных с происхождением ячеек и явными пропусками |
| `acquire_orthogonal_metadata.py` | Дополнительные метаданные Europe PMC/PMC, ORCID/ROR и индексные ссылки Common Crawl |
| `import_portable_bundle.py` | Контролируемый импорт переносимого набора через явную проверку |

Метаданные, доступ к аннотации, доступ к полному тексту и независимая научная поддержка — разные возможности. Индексный указатель Common Crawl не является скачанной архивной страницей. Замена поставщика не означает автоматической эквивалентности недоступной базе.

## Минимальный публичный Search

Используйте Python того же окружения, из которого взята команда `hermes`. Корневой каталог результатов должен существовать, иметь абсолютный путь и не быть символической ссылкой. Каждый запуск создаёт новые закрытые подкаталоги.

```sh
UDR_PYTHON=/absolute/path/to/hermes/venv/bin/python
UDR_HERMES=/absolute/path/to/hermes/venv/bin/hermes
UDR_SCRIPTS="$HERMES_HOME/plugins/ultra-deep-research/skills/research/scripts"
mkdir -p "$HERMES_HOME/research-runs"
"$UDR_PYTHON" "$UDR_SCRIPTS/run_beta_search.py"   --question 'State exactly what FAIR principle F1 requires.'   --hermes "$UDR_HERMES"   --output-root "$HERMES_HOME/research-runs" --public-query-ack
```

`--public-query-ack` подтверждает допустимость передачи вопроса и соответствующих материалов настроенным внешним исследовательским и модельным маршрутам. Флаг не превращает закрытые данные в публичные и не предоставляет права на распространение источника.

Для Ultra и Academic действуют те же правила окружения и каталогов:

```sh
"$UDR_PYTHON" "$UDR_SCRIPTS/run_beta_research.py"   --mode ultra --domain-first --question 'Ваш ограниченный публичный вопрос'   --hermes "$UDR_HERMES" --output-root "$HERMES_HOME/research-runs" --public-query-ack

"$UDR_PYTHON" "$UDR_SCRIPTS/run_beta_research.py"   --mode academic --question 'Ваш ограниченный публичный вопрос обзора'   --academic-documents /absolute/path/documents.json   --hermes "$UDR_HERMES" --output-root "$HERMES_HOME/research-runs" --public-query-ack
```

Перед добавлением `--planning-dir`, `--decomposition`, `--coverage-frame`, `--adaptive-coverage-batches`, `--academic-datasets` и бюджетов контрольного поиска изучите `--help` конкретного сценария. `--academic-documents` предоставляет материалы для разбора, но сам по себе не закрепляет весь последующий поиск источников.

## Начальные пределы плана в этой версии

| Режим | Поисковые обращения | Максимум источников | Вызовы модели | Время, секунды | Предел оценки, USD |
|---|---:|---:|---:|---:|---:|
| Search | 2 | 3 | 2 | 120 | 0.02 |
| Deep | 8 | 16 | 4 | 600 | 0.20 |
| Ultra | 16 | 32 | 8 | 1200 | 0.50 |
| Academic | 12 | 40 | 64 | 3600 | 0.30 |

Это начальные константы плана, а не обещанное время завершения или актуальные тарифы моделей. Первоначальное планирование имеет отдельный бюджет: один вызов, 60 секунд, оценка до 0,01 USD. Дополнительные стадии ограничиваются своими пределами и остатком общего бюджета. Фактическое исполнение определяется квитанциями. Подписочный учёт OAuth `included` сохраняется вместе с числом токенов и измеренным временем.

## Какие артефакты читать

| Артефакт | Значение |
|---|---|
| `plan.json`, `planning-run.json` | Область плана и наблюдение, на основании которого он создан |
| `attempt.json` | Намерение, пределы и правило повтора до потенциально внешней операции |
| `effective-runtime.json`, `effective-model-entry.json` | Связанные хешами фактические настройки среды и модели |
| `capture.json`, файлы текстов/PDF | Исходы получения и сохранённые байты источников |
| `source-selection.json` | Выбранный источник, пригодные, отсутствующие и непрочитанные части; исходный журнал сохранён |
| `model-usage.json`, `cost-accounting.json` | Наблюдённый расход и интерпретация денежной оценки |
| `model-candidate.json`, записи проверки | Кандидаты положений и область их проверки |
| `result.json`, `result.md`, когда сформированы | Структурированный результат и читаемое представление |
| `failure.json`, записи сверки | Ошибка или неизвестный исход, допустимость новой внешней попытки |

Для работ используется перечень документов с `document_id`, `title`, `url`, `path`, `read_scope` (`full_text` либо поддержанная форма аннотации). Полный контракт конкретного сценария приведён в [навыке выпуска](https://github.com/olegeklepikov-collab/ultra-deep-research/tree/v0.41.0a1-r153-v22/skills/research). Чтение PDF может быть частичным из-за времени, размера, извлечения или ограничений изображения. Отсутствие извлечённого визуального элемента не доказывает отсутствие значимого рисунка, таблицы или формулы на исходной странице.

## Остановка и сверка

Достижение бюджета сохраняет частичный результат. Отсутствие обязательного первичного чтения запрещает более сильное заявление об изучении. Квитанция выбора не делает непрочитанные части покрытыми. Изменение настроек требует нового запуска. При неизвестном внешнем исходе сначала изучите сохранённую попытку и соответствующую команду сверки: ошибка локального процесса сама по себе не является основанием для повтора.
