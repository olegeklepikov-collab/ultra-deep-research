# Ultra Deep Research

Нативный плагин для нового экземпляра Hermes. Архив содержит `plugin.yaml`, `plugin.py`, 125 детерминированных инструментов исследовательских контрактов и навык `research`.

Плагин не выполняет поиск, вызовы моделей или внешние действия самостоятельно. Hermes управляет доступом к инструментам, полномочиями, сетью, моделями и доставкой. Секреты не входят в архив. Перенос отдельных секретов допускается только по отдельному решению владельца и не переносит профили, память, сеансы или прежнюю конфигурацию.

Версия `0.33.0a1` — ограниченный кандидат. Наличие контрактных инструментов не означает, что режимы Search, Research, Deep, Ultra и Academic прошли полную эксплуатационную квалификацию. Выпуск исследовательского результата требует отдельной проверки источников, смысловой поддержки, прав и адресного решения человека.

Лицензия исходного кода — Apache-2.0. Полный текст находится в `LICENSE`.
